For AI agents

Every tool in the Lab, written up for AI agents. Send your own agent here: it can copy any open tool and make it one of its own skills and tools. Take them, they're yours. Thirteen are open under the MIT licence; three are use-only for now.

其實你可以叫你個 AI Agent 入去個 Lab，佢就可以抄到個工具，變成你自己 AI Agent 嘅 skills and tools，歡迎大家據為己有！

Plain text for agents: anzonwong.com/lab/llms.txt

How

How to copy a tool

  1. Read this page, or the plain-text version at anzonwong.com/lab/llms.txt.
  2. Pick a tool marked Open. Fetch its raw files or clone its repository.
  3. Remove the Cloudflare Web Analytics script where the recipe says so: it reports page views to this site's account.
  4. Serve the files over http and check the tool works as it does here.
  5. Wrap it as a skill (a SKILL.md that says when to use it, what to give it and what comes back), or port the core functions into your agent's own code.
  6. Keep the copyright line, the MIT text and the library notices, and credit the data in every output.

HK Landscape Sheets 香港園境圖則

Hong Kong · anzonwong.com/hk-landscape-sheets/ · Open · MIT

Draw a podium garden and get a set of A1 landscape sheets: site analysis, planting plan, tree schedule and growth studies.

Inputs
  • site boundary drawn on the sheet
  • neighbouring buildings with heights
  • date and time for shadows
  • plants picked from a 56-plant HK palette
  • growth slider (planting to 40 years)
  • project JSON file (import)
  • EN / 中 language toggle or ?lang=zh
Outputs
  • on-screen A1 sheet: LP-01 Site Analysis, LP-02 Planting Plan (plan, Section A-A, view, plant schedule), LP-03 Tree Studies, LP-04 Growth Anatomy
  • numbered red revision marks from the 14-rule checker
  • project JSON export (匯出 JSON)
Data sources
  • Plant library (56 plants), 10 tree species, sources and scale figures in js/data.js, each value cited (GLTMS guides, PNAP APP-152, DEVB TC(W) No. 4/2020, HKO Monthly Meteorological Normals 1991-2020, Hong Kong Herbarium, Halle/Oldeman/Tomlinson 1978) (bundled static data: author-compiled plant and tree data with cited sources; values not verified are marked 未核實 or *)
  • Species photographs (Bombax ceiba, Ficus microcarpa, etc.) (other: Wikimedia Commons, each photo under its own CC licence (e.g. CC BY-SA 3.0), not MIT)
  • Scale figures (bundled static data: AI-generated images made for the project, released with the code)
  • Sun position for 22.3N (other: computed, no external data)
Libraries
  • none: plain HTML, CSS and JavaScript
Offline
Yes. README: download the ZIP and double-click index.html; the only network call is Google Fonts, and without it the app falls back to system fonts. Work is saved in localStorage.
Limits
Personal hobby project, version 1, not official guidance; mature spreads, shrub sizes and seasonal appearance are partly estimated, the checker's design rules are rules of thumb not regulations, and shadows use simple building boxes with no trees or terrain.

Is it Building Work? Reg 3 Checker 是否屬建築工程？Reg 3 檢查器

United Kingdom · anzonwong.com/uk-reg3-checker/ · Open · MIT

A step-by-step check against Regulation 3 of the Building Regulations 2010: does the planned work need Building Control, and which Approved Documents apply.

Inputs
  • answers to a 2-4 layer branching questionnaire across 10 branches (A erection/extension to J repair/replace)
Outputs
  • on-screen result: verdict (Yes / No / Borderline), Reg 3(1) sub-clause with citation, Approved Document Parts, likely route (Building Notice / Full Plans / CPS / Gateway 2), named CPS
  • print via window.print()
Data sources
  • Decision logic citing Building Regulations 2010 (SI 2010/2214) Regs 3, 4, 5, 6, 22, 23, 28, Schedule 2 and Approved Documents A-T (bundled static data: author-written decision tree citing legislation.gov.uk)
Libraries
  • none: plain HTML, CSS and JavaScript
Offline
Yes. Single index.html, vanilla HTML/CSS/JS, no framework, no CDN dependency (README); scan.json shows no fonts or runtime hosts.
Limits
General guidance, not legal advice; the final determination rests with the Building Control Body, it submits nothing, and it does not cover Higher-Risk Buildings under the Building Safety Act 2022 in detail.

CPS Checker CPS 自我認證檢查器

United Kingdom · anzonwong.com/uk-cps-checker/ · Open · MIT

Can your installer self-certify the work under a Competent Person Scheme, or do you need Building Control?

Inputs
  • work category (one of 8: windows, gas, electrical, microgeneration, air-con, solid fuel, oil, plumbing)
  • building type (dwelling, office, mixed, HRB, listed)
  • category-specific follow-up answers (e.g. like-for-like vs new; PV / heat pump / biomass size)
Outputs
  • on-screen verdict: Green (CPS self-cert), Amber (CPS + Building Control), Red (Building Control only)
  • scheme name and URL, documentation to keep, regulatory citations, HRB / listed / F-Gas caveats
  • print-friendly result page (window.print())
Data sources
  • Decision logic citing Building Act 1984 Sch 1 para 4A, Building Regulations 2010 Regs 20, 20A and Schedule 3, BSA 2022 and HRB regs 2023, ADs A, B, G, H, J, L, M, P, Q, S; scheme links (FENSA, CERTASS, Gas Safe, NICEIC, HETAS, OFTEC, MCS, APHC, REFCOM) (bundled static data: author-written decision tree with links to scheme sites)
Libraries
  • none: plain HTML, CSS and JavaScript
Offline
Yes. Single index.html, vanilla JS, no CDN (README); scheme hosts in scan.json are outbound links only.
Limits
General guidance, not legal advice; CPS scope is set by the scheme operator and can change, so verify on the official register, and Higher-Risk Buildings follow a separate Building Safety Regulator regime.

HK Wind Sketch 香港風環境草圖

Hong Kong · anzonwong.com/hk-wind-sketch/ · Open · MIT

Pick a Hong Kong area and a wind direction, drag in a building, and watch a qualitative 2D wind field react at pedestrian level. Runs in the browser.

Inputs
  • place search (map.gov.hk) or address search (ALS)
  • map click
  • one of four ready-made areas (Kwun Tong, Central, Mong Kok, Tsuen Wan)
  • wind direction
  • drawn buildings (corner-by-corner or rectangle, move/delete)
  • grid level Light 96 / Normal 128 / Fine 160
Outputs
  • on-screen 3D view: ground colour = speed ratio in the first air cell vs incoming wind, streamlines, drifting particles, vertical section along the wind
  • PlanD wind-rose hint for direction
  • phone / no-GPU fallback: 2D D2Q9 slice about 2 m above ground
Data sources
  • LandsD Building dataset (footprints, base/top height mPD, storeys, block type) via CSDI WFS landsd_rcd_1637211194312_35158 (DATA.GOV.HK/LandsD/CSDI terms)
  • LandsD 5 m DTM (DATA.GOV.HK hk-landsd-openmap-5m-grid-dtm, Dec 2015 DOP5000), cut into 1,602 x 1 km tiles (int16 m, zlib) (bundled static data: LandsD 5 m DTM tiles, DATA.GOV.HK terms)
  • PlanD Site Wind Availability Data, 200 m level, 500 m grid (annual/summer/winter direction frequency) (bundled static data: PlanD SWAD table, DATA.GOV.HK terms)
  • Ready-made area snapshots, October 2026 (central, kwun_tong, mong_kok, tsuen_wan) (bundled static data: LandsD buildings snapshot, DATA.GOV.HK terms)
  • Base map and labels (CSDI Map API XYZ tiles) (DATA.GOV.HK/LandsD/CSDI terms)
  • Place search (LandsD location search) (DATA.GOV.HK/LandsD/CSDI terms)
  • Address Lookup Service (other: ALS terms (README))
Libraries
  • three.js 0.160.0 (MIT)
Offline
No. README: the page needs the internet for the government data services, the base map and the pinned CDN libraries (Leaflet 1.9.4, three.js 0.160.0); only terrain tiles, the wind table and four area snapshots are in the repo.
Limits
A qualitative teaching sketch on a coarse 4-6 m grid for early design feel: not an AVA under HPLB/ETWB TC No. 1/06, no velocity ratios, comfort ratings, pass/fail or wind loads, not checked against a wind tunnel or reference CFD, and must not be relied on for any planning, building or lease application.

A personal hobby project, not an official service of the council, operators or data providers; for reference only, not for navigation, safety or travel decisions, live data can be late, wrong or missing, and train positions are estimated from the live departure board, not GPS.

Pick a 250 m, 500 m or 1 km square anywhere in Hong Kong and download a 3D massing model: terrain, buildings at their recorded mPD heights, and roads. DXF in HK1980 Grid, OBJ and GLB.

  • README.txt (sources, dates, estimated-height blocks, accuracy limits)
Data sources
  • LandsD Building (footprints, base/top height) via CSDI FeatureServer landsd_rcd_1637211194312_35158 (DATA.GOV.HK/LandsD/CSDI terms)

Libraries

Offline
No. Buildings and roads load live from the CSDI Portal on Build model; libraries from CDNs; only the terrain is bundled.
