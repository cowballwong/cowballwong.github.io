建立只屬於你的 AI 代理人

一對一網上課，毋須編程：完成後，你會擁有一個熟悉你工作的代理人。

學生 Portal · 報名 / Student portal
第一步 · 基礎班

你的私人 AI 代理人

形式
一對一，Google Meet 網上授課，同時顯示英國及香港時間
堂數
Class 0（第一堂，免費，60 分鐘）+ Class 1–5，每堂 1 小時
Class 0
免費諮詢：了解你的工作和需要，令 Class 1–5 切合你的情況。上完 Class 0 才可預約 Class 1–5。
學費
HK$2,400（香港）/ £250（英國），Class 1 後付款
對象
任何人，毋須編程。事前不用安裝，Class 1 一同安裝
  1. 開機 你自己的 AI 代理人，電腦及手機都用得；它會讀你的項目資料夾，刪除任何東西前先問你。
  2. 拆解原理 教它按手冊做事：開好一個真項目，把你的手稿讀成設計表。
  3. 一齊改造 一個助手起 SketchUp 模型，另一個負責檢查；你只需跟你的代理人說。
  4. 由讀到做 多個助手同時出三張效果圖、Word 說明及網頁初稿，每份都經檢查。
  5. 獨一無二 一頁項目網頁，你在手機批准後才正式發出。

兩個版本，五堂內容相同：Hermes Agent + Ollama，毋須 Claude 帳戶（香港、中國內地）· Track B Claude 應用程式，需 Claude Pro（英國）。未能決定？報名時選「未知」便可。

第二步 · 進階班（建築行業）

由投標到交樓

接受報名 · 10 月 24 日起，逢星期六

形式
用你的代理人配合 Revit，把一個項目由投標做到交樓
堂數
共 5 堂，功課須於上堂前一天交回
學費
全期 HK$3,400（香港）/ £350（英國）
對象
建築業界，須先完成基礎班（可申請豁免）；自備已安裝 Revit 的 Windows 電腦
  1. 投標 合規核對、技術建議書、收費表格。
  2. 可行性研究 地盤限制、樓面面積、體量、報告。
  3. 方案及法定審批 Revit 方案、一般建築圖則、回覆意見。
  4. 詳細設計 LOD 300 圖則、招標文件、回標報告。
  5. 施工至交樓 會議紀錄、RFI、缺陷清單、交樓文件。

在學生 Portal 預約。已完成基礎班可直接揀時間；未讀基礎班，可在 Portal 申請豁免。
