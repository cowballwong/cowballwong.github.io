Podium Pattern Studio 平台外牆圖案工作室

先設定平台立面，再由幾條簡單規則決定每塊穿孔板或每組鰭片的通透程度：你拖動的吸引點、外牆朝向、每層用途，以及你親手塗上的私隱遮罩。然後限定板材種類數目，漸變便會收歸為製造商真正做得到的幾款尺寸。板材排列可匯出為 SVG 及分層 DXF，板材表可匯出為 CSV。以往要用 Rhino 及 Grasshopper 做的研究，現在在瀏覽器內便可完成。

運作方式
  1. 網格。立面劃分為模數：橫向等分成若干列，每層再按最接近模數高度的整數分行。
  2. 驅動因素。每個驅動因素為每塊板給出 0（實）至 1（通）的通透度。吸引點：與最近一點的距離，在影響半徑內平滑過渡。朝向：簡化的日照估算，西南向最高，愈高的位置略高。樓層用途：停車場及機房通透，商舖實心。遮罩：你塗在哪裏，便按你塗的值。
  3. 混合。各驅動因素按你設定的比重平均。某因素在某板上不起作用（例如沒有吸引點，或該處未有塗繪），便不計入該板的平均值。結果再按比例拉闊，令最實的板取「最實」通透率，最通的板取「最通」通透率。
  4. 收歸。平滑結果收歸為 N 款：由最實到最通等距分級，或每款板數相同。每款即一個孔徑（取整至毫米，孔距相同）或一個鰭片角度（每 5 度一級），即一套沖孔模具或一款支架。
  5. 檢查。少於 3 塊的種類會被標示：製造商會問值不值得為它另開模具。不同層高的樓層板材尺寸不同，因此板材表亦會列出每個「尺寸 × 種類」組合的數量。
限制
  • 日照朝向因素只是設計上的估算，並非太陽輻射或採光計算結果，亦不考慮鄰近建築物及遮擋。
  • 平面只處理單一平面長方形立面，不處理弧面、轉角、退台，亦不計模數網格以外的板縫。
  • 製造孔徑及鰭片角度只屬幾何。邊距、孔間寬度、板厚、固定件及公差須由幕牆工程師及製造商決定。
  • 法規通透面積只是數字，本工具不列明任何通風、防火或其他法定要求。
